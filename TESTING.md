# Werewolf reconstruction: test coverage and limits

Run `npm ci`, `npm run build`, `npx tsc --noEmit` and `npm test` with Node 22+.

The automated suite checks that every currently implemented role can be selected, dealt, take a first-night turn and reach morning in a simulated interface. It checks that the role lineup starts empty and the start-button count updates, opens every role-detail view, verifies artwork and offline-cache entries, and exercises the implemented global settings (first-night safety, death-role reveal, secret voting, skip votes, point-based distribution for all player counts, all difficulty modes, weighted chance exclusions and Madman compatibility, random player assignment, Madman compatibility, the Madman count, passive-role wait, optional game sounds and the discussion timer). It also tests selected multi-night flows, including silent Police detentions in different turn orders, delayed investigation reports, Hypnotist, Madman, Lovers, the Gambler’s next-morning escape, and a Chef with insufficient guests, plus individual engine interactions and player-avatar assignment, bottom-sheet navigation, and explicit delete mode. Disguised and Police-detained Journalist tests check that the newspaper is silently suppressed in either turn order. The discussion timer is tested against elapsed wall time, adding a minute and returning from the background. Simulated service-worker tests exercise cache installation, update cleanup, offline navigation and GitHub Pages subdirectory paths. Ranking tests cover faction and independent winners and saving a completed game once.

This is not exhaustive validation of every role interaction, action order or win condition, nor a comparison against the running original APK. Most UI tests use a simulated DOM. A Chromium mobile-emulation smoke test additionally checks 320px and 390px phone layouts, 44px role controls, scrolling with the fixed bar, screen/turn scroll reset, role details, game start, offline reload and artwork, avatar transfer, a gallery file upload, a touch-drawn Journalist newspaper, direct voting, and offline audio phase playback attempts. Physical-device touch/camera, browser installation and broader offline gameplay still need testing. Run the optional smoke test against a production preview with `CHROMIUM_PATH=/path/to/chromium npm run test:browser`. All roles have an optional minimum wait, and roles with configurable active abilities have additional settings; their defaults retain the existing rules. Mechanics noted as provisional in `APK_INSPECTION.md` remain provisional even when tests pass.
